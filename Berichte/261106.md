## Übung 3.2 (Burp Suite Intro)

### Intercepting HTTP Requests mit Burp Suite


- Burp Proxy sitzt als „Man-in-the-Middle“ zwischen Browser und Webserver. Jede Anfrage geht zuerst durch Burp.
- Intercept on: Burp hält jeden Request an, bevor er zum Server geht. Man kann ihn ansehen und bearbeiten (z. B. Parameter, Header, Cookies).
- Forward schickt den (ggf. veränderten) Request weiter, Drop verwirft ihn.
- Der Traffic läuft normal durch, wird aber weiterhin aufgezeichnet wenn man interept off schaltet
- Alles, was vom Client kommt, kann manipuliert werde bieten daher keinen Schutz.
